## Repeatable commands and validation workflows

Added package scripts:

```text
npm run baseline:bundle
npm run baseline:inventory
```

`baseline:bundle` runs a production Vite build and writes
`docs/issues/frontend-bundle-baseline.md`. The report includes raw and gzip
estimates for all emitted files, entrypoints, and the largest JavaScript/CSS
chunks.

Registered validation workflows:

- `baseline-bundle`
- `baseline-inventory`
- `frontend-test`
- `frontend-typecheck`
- `php-lint`
- `laravel-test`

## Definition of done for subsequent extraction work

Every Phase 1–6 change must satisfy the following checklist:

- [ ] Record the relevant before/after bundle or module-size measurement.
- [ ] Preserve route URLs, authentication behavior, and API response
      compatibility.
- [ ] Add or update focused tests for the extracted hook, service, component,
      policy, request, or resource.
- [ ] Run the relevant frontend and backend validation workflows.
- [ ] Confirm no new TypeScript, PHP syntax, or Laravel test regressions.
- [ ] Verify responsive visual behavior when CSS or page composition changes.
- [ ] Remove old code only after import/search checks and route tests confirm
      it is unreachable.
- [ ] Update the relevant inventory or architecture documentation.

## Phase 0 boundary

No route splitting, component extraction, CSS deletion, controller
decomposition, response-envelope migration, or migration-chain rewrite was
performed in this phase. Those remain in Phases 1–6 of the approved plan.
